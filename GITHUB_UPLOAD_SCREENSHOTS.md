## 📤 Stap 4: Upload je Foto

### A. Klik rechtsboven op "Add file"

```
┌─────────────────────────────┐
│  [➕ Add file ▼]           │  ← Klik hier!
│   ├─ Create new file       │
│   └─ Upload files    ← !!  │
└─────────────────────────────┘
```

### B. Kies "Upload files"

Je ziet nu een upload pagina:

```
┌──────────────────────────────────────────────────────┐
│  Upload files                                        │
│                                                      │
│  ┌────────────────────────────────────────────────┐ │
│  │                                                │ │
│  │         Drag files here to add them            │ │
│  │                                                │ │
│  │              choose your files                 │ │
│  │                                                │ │
│  └────────────────────────────────────────────────┘ │
│                                                      │
│  Commit changes                                      │
│  ┌────────────────────────────────────────────────┐ │
│  │ Add hero background photo                      │ │
│  └────────────────────────────────────────────────┘ │
│                                                      │
│  [✓] Commit directly to claude/zie-feedback... branch│
│                                                      │
│  [ Commit changes ]                                  │
└──────────────────────────────────────────────────────┘
```

### C. Sleep je foto erin

**Op je computer:**
1. Zoek je gym foto
2. Hernoem naar: `hero-background.jpg`
3. Sleep de foto naar het "Drag files here" gebied

**OF**

Klik op "choose your files" en selecteer de foto.

### D. De foto is toegevoegd!

```
┌──────────────────────────────────────────────┐
│  ✅ hero-background.jpg  (2.3 MB)           │
│  [🗑️ Remove]                                │
└──────────────────────────────────────────────┘
```

### E. Vul commit bericht in

```
┌──────────────────────────────────────────────┐
│  Commit changes                              │
│  ┌──────────────────────────────────────────┐│
│  │ Add hero background photo            │← │ Typ hier
│  └──────────────────────────────────────────┘│
│                                              │
│  [✓] Commit directly to the branch          │
│                                              │
│  [ Commit changes ]  ← Klik deze groene knop│
└──────────────────────────────────────────────┘
```

### F. Klik "Commit changes"

⏳ GitHub uploadt nu je foto...

✅ **Klaar! Je foto staat op GitHub!**

## 🔄 Stap 5: Herhaal voor Testimonial Foto's

### A. Ga terug naar images folder

Klik bovenaan op: `images`

```
public / images /          ← Klik hier om terug te gaan
```

### B. Klik op de `testimonials` folder

```
📁 testimonials/          ← Klik hier
```

### C. Upload 3 foto's tegelijk

1. Klik: **[➕ Add file]** → **Upload files**
2. Sleep alle 3 de foto's tegelijk:
   - `sarah.jpg`
   - `mark.jpg`
   - `lisa.jpg`
3. Commit bericht: `Add testimonial photos`
4. Klik: **[Commit changes]**

✅ **Alle foto's zijn geüpload!**

## 🆘 Hulp Nodig?

### Ik zie geen "Add file" button
→ Je hebt geen schrijfrechten. Check of je ingelogd bent op het juiste GitHub account.

### Upload duurt heel lang
→ Je foto is te groot. Comprimeer eerst op [TinyPNG.com](https://tinypng.com)

### Foutmelding bij committen
→ Check of je op de juiste branch zit (niet "main")

### Kan folder niet vinden
→ Gebruik deze directe links:
- Images: `github.com/jeroenvanduijn/28daykickstart/tree/claude/zie-feedback-011CUpHsHkwmsT9NiPzPNPyh/public/images`
- Testimonials: `github.com/jeroenvanduijn/28daykickstart/tree/claude/zie-feedback-011CUpHsHkwmsT9NiPzPNPyh/public/images/testimonials`

Veel succes! 🎉
