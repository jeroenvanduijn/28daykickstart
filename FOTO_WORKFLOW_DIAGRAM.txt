║                          BELANGRIJKE PUNTEN                                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

📌 GitHub is NIET zoals Google Drive
   Je upload niet direct naar GitHub via een website
   Workflow: Lokaal toevoegen → Git commit → Git push → GitHub

📌 Foto's horen in de `public` folder
   Niet in `src`, niet in `components`, alleen in `public`!

📌 Bestandsnamen zijn hoofdlettergevoelig
   "Hero-Background.JPG" ≠ "hero-background.jpg"
   Gebruik exact: hero-background.jpg (kleine letters!)

📌 Eerst foto's, dan code aanpassen
   1. Foto's lokaal toevoegen
   2. Testen met npm run dev
   3. Dan code aanpassen
   4. Alles committen en pushen

📌 De public folder wordt automatisch gehost
   Alles in `public` is toegankelijk via URL
   public/images/hero.jpg → yourdomain.com/images/hero.jpg
